# 🎬 Netflix Sign In Page

A simple **Netflix-inspired Sign In page** built using HTML and CSS.
This project focuses on creating a clean, responsive authentication interface inspired by Netflix's visual style.

## ✨ Features

* Netflix-inspired UI
* Email/phone and password fields
* Remember Me checkbox
* Need Help link
* Sign Up section for new users
* Google reCAPTCHA information section
* Netflix favicon and logo
* Clean and minimal layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* SVG

## 📂 Project Structure

```text
Netflix-Login/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.

## 📸 Preview

The page provides a Netflix-inspired sign-in experience with a dark, minimal interface and familiar Netflix branding.

This project was created as a **frontend practice project** to improve skills in:
